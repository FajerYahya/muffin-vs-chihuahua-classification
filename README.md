# muffin-vs-chihuahua-classification
# Muffin vs Chihuahua Image Classification

This project classifies images as either Muffin or Chihuahua using Deep Learning.

## Models Used

1. Custom CNN
2. CNN with Batch Normalization and Dropout
3. Transfer Learning using ResNet50

## Dataset

Muffin vs Chihuahua Dataset from Kaggle

## Technologies

- Python
- TensorFlow
- Keras
- Google Colab
